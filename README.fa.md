## مشکل چیست؟

اگر فارسی می‌نویسید و از ترمینال استفاده می‌کنید، این را می‌شناسید: متن فارسی و انگلیسی که با هم می‌آیند، جابه‌جا نمایش داده می‌شوند. نام فایل به سمت اشتباه خط می‌پرد، عدد نسخه به لبهٔ دیگر می‌رود، و پرانتزها وارونه‌اند. هیچ حرفی خراب نشده است، فقط ترتیب دیداری آن‌ها غلط است.

دلیلش فونت یا کدگذاری نیست. دلیلش این است که بیشتر شبیه‌سازهای ترمینال الگوریتم دوجهته (BiDi) یونیکد را پیاده‌سازی نکرده‌اند. ترمینال یک شبکه از خانه‌هاست، نه یک پاراگراف، و بازچینش متن با برنامه‌هایی که مستقیم روی ستون‌ها می‌نویسند در تضاد است.

نتیجه این است که Claude Code، که یک عامل هوش مصنوعی در ترمینال است، برای فارسی‌زبانان عملاً ناخوانا می‌شود.

## Kivun Terminal چه می‌کند؟

Kivun همان Claude Code واقعی و کامل را اجرا می‌کند، اما در محیطی که راست‌به‌چپ را درست نمایش می‌دهد:

- **نمایش درست دوجهته.** یک لایهٔ تبدیل روی خروجی Claude Code نشانه‌های جهت یونیکد را تزریق می‌کند، بنابراین متن فارسی از راست چیده می‌شود و کلمهٔ انگلیسی یا مسیر فایلِ داخل جمله دقیقاً سر جای خودش می‌نشیند.
- **تعویض زبان صفحه‌کلید مثل ویندوز.** با Alt+Shift بین زبان‌هایی که در ویندوز دارید جابه‌جا می‌شوید، با همان ترتیب.
- **بدون نیاز به دانش فنی.** پوشهٔ پروژه را در یک پنجرهٔ ساده انتخاب می‌کنید. نیازی به تایپ هیچ فرمانی نیست.
- **نصب یک‌کلیکی.** Node.js و Git و خود Claude Code در پس‌زمینه نصب می‌شوند.
- **نوار وضعیت زنده.** مدل فعال، مصرف پنجرهٔ زمینه، تعداد توکن‌ها و زمان بازنشانی سهمیه.

> نکتهٔ مهم: هیچ فایل سیستمی جایگزین نمی‌شود و به مخزن گواهی‌های ریشه دست زده نمی‌شود. کل کد باز است و قابل بازبینی.

## شروع سریع

**ویندوز**

۱. آخرین نصب‌کننده را از [صفحهٔ انتشارها](https://github.com/noambrand/kivun-terminal-wsl/releases/latest) دانلود کنید (`Kivun_Terminal_Setup.exe`).
۲. روی فایل راست‌کلیک کنید و **Run as administrator** را بزنید. این مرحله برای نصب WSL لازم است.
۳. پس از پایان نصب، از منوی Start گزینهٔ **Kivun Terminal** را باز کنید.
۴. پوشهٔ پروژه را انتخاب کنید و شروع کنید. برای پاسخ‌های فارسی، مقدار `RESPONSE_LANGUAGE` را در `config.txt` روی `persian` بگذارید.

**لینوکس**

بستهٔ tar را از همان صفحهٔ انتشارها بگیرید و `install.sh` را اجرا کنید.

## پیش‌نیازها

- ویندوز ۱۰ نسخهٔ ۱۸۰۳ به بالا یا ویندوز ۱۱، یا یک توزیع لینوکس
- یک اشتراک Claude (Pro، Max یا Team) یا کلید API از Anthropic

## چرا فقط ویندوز و لینوکس؟

چون روی مک هیچ ترمینال بومی‌ای امروز متن درهم‌آمیختهٔ راست‌به‌چپ را درست نمایش نمی‌دهد. Apple Terminal اصلاً الگوریتم دوجهته ندارد، iTerm2 ترتیب حروف را برعکس می‌کند و WezTerm شکل‌دهی را اشتباه انجام می‌دهد. ما پشتیبانی از مک را عرضه کردیم و سپس آن را برداشتیم، چون کاری از دست ما برای میزبانی که بازچینش نمی‌کند برنمی‌آید.
